# Astro Bot MVP

Пробный Telegram-бот для расчёта натальной Венеры.

Что умеет:
- принимает дату, время и город рождения;
- геокодирует город;
- определяет часовой пояс по координатам;
- переводит локальное время рождения в UTC;
- рассчитывает натальные планеты через Swiss Ephemeris;
- рассчитывает дома Placidus;
- определяет фактический дом Венеры по точным куспидам;
- показывает включённые знаки в домах;
- рассчитывает полнознаковые аспекты Венеры;
- отдельно считает точность аспектов по градусам;
- усиливает точные аспекты и точные связи с высшими планетами.

Важно:
Для исторически точного часового пояса используется стандартная база zoneinfo.
Геокодирование в MVP идёт через Nominatim/OpenStreetMap. Для продакшена лучше заменить
на более надёжный геокодер и обязательно тестировать исторические часовые пояса.

Запуск:
1. Создайте Telegram-бота через @BotFather.
2. В терминале:
   export BOT_TOKEN="..."
3. pip install -r requirements.txt
4. python bot.py
